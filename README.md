

Личный календарь с фиксированным недельным расписанием и тренировками.
Чистый HTML/CSS/JS, без сборки, без бэкенда, без аналитики. Все отметки — в `localStorage` устройства.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка трёх экранов (календарь, день, тренировка) + настройки |
| `styles.css` | iOS-стиль, светлая/тёмная тема, safe-area, анимации |
| `app.js` | логика: календарь, отметки, шторки, статистика, уведомления |
| `data.js` | недельный шаблон и тренировки — **здесь меняется расписание** |
| `sw.js` | Service Worker (offline-first, cache-first) |
| `manifest.json` | манифест PWA |
| `icons/` | иконки 180/192/512 |
