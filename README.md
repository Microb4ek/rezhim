# Режим — PWA-трекер недельного расписания

**Живая версия:** https://microb4ek.github.io/rezhim/

Личный календарь с фиксированным недельным расписанием и тренировками.
Чистый HTML/CSS/JS, без сборки, без бэкенда, без аналитики. Все отметки — в `localStorage` устройства.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка трёх экранов (календарь, день, тренировка) + настройки |
| `styles.css` | iOS-стиль, светлая/тёмная тема, safe-area, анимации |
| `app.js` | логика: календарь, отметки, шторки, статистика, уведомления |
| `data.js` | недельный шаблон и тренировки — **здесь меняется расписание** |
| `sw.js` | Service Worker (offline-first, cache-first) |
| `manifest.json` | манифест PWA |
| `icons/` | иконки 180/192/512 |

## Как разместить

Приложение уже опубликовано на GitHub Pages из этого репозитория (main / root).
Любой push в main обновляет сайт через ~30 секунд.

Если нужно развернуть заново:

PWA требует HTTPS (или `localhost`). Самый простой вариант — GitHub Pages:

1. Создайте репозиторий, залейте содержимое этой папки в корень (или в подпапку — пути относительные).
2. Settings → Pages → Source: `main` / root.
3. Откройте `https://<user>.github.io/<repo>/` в Safari на iPhone → «Поделиться» → «На экран Домой».

Подойдёт любой статический хостинг: Netlify, Cloudflare Pages, Vercel.

## Обновление

Кэш строго cache-first: при изменении любого файла **поменяйте `VERSION` в `sw.js`**
(и при желании `APP_VERSION` в `app.js`). Открытое приложение покажет тост «Доступно обновление».

## Изменить расписание

Редактируйте `data.js`. Идентификаторы отметок строятся из дня недели и индекса пункта
(`monday:2`), поэтому вставка пункта в середину списка сдвинет старые отметки того дня.
Добавляйте новые пункты в конец списка — сортировка по времени происходит автоматически.

## Ограничения iOS

- Системный будильник и пуш-уведомления при закрытом приложении недоступны для веб-приложений.
  Уведомления работают только пока приложение открыто (и только после установки на экран Домой).
- Данные живут в памяти Safari/PWA. Для переноса на другое устройство есть
  «Скопировать резервную копию» в настройках.
